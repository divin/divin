# Hi. I'm Divin 👋

<img src="assets/wave.png" align="right" height="294"/>

I'm a **Data Scientist** with a **background in Physics** — at work I train machine learning models, build data pipelines, and dig into complex data to find cool insights. In my free time, I do a lot of **engineering**: my homelab runs its own **local LLM**, and most of the tools around it are built by me, for me.

The tools are very specific to my setup, but the ideas behind them might be useful to others — so they're all public. Everything is **self-hosted**, **privacy-friendly**, and named in **Japanese**: [tana](https://github.com/divin/tana) (棚, "shelf"), [omozo](https://github.com/divin/omozo) (思 + 蔵, "a vault of thoughts"), [matomeru](https://github.com/divin/matomeru) (まとめる, "to bring together"). I'm currently learning the language, and the repo names double as practice.

When I need a break from my own infrastructure, I dabble in **music**, **drawing**, and **game development**. The last one is a perfect mix of all my interests.

## 🖥️ Self-hosting & local AI

- [**Omozo**](https://github.com/divin/omozo) — local-first memory and document-retrieval layer for a small local agent, exposed through exactly three MCP tools.
- [**Sagashi**](https://github.com/divin/sagashi) — self-hosted MCP server for web search, Reddit search, and page fetching.
- [**Ninmu**](https://github.com/divin/ninmu) — focused MCP tool wrapper for [Vikunja](https://vikunja.io/) and [NoteDiscovery](https://www.notediscovery.com/), built for small local LLMs.
- [**Matomeru**](https://github.com/divin/matomeru) — cron-driven digest generator for Reddit and arXiv, summarized by a local LLM against your interest profile.
- [**Koebako**](https://github.com/divin/koebako) — voice-note ingestion and transcription service for the [Pebble Index](https://repebble.com/index).
- [**Koemichi**](https://github.com/divin/koemichi) — routes Koebako transcripts into memo and journal notes.
- [**Guai**](https://github.com/divin/guai) — privacy-friendly health tracker built around a [Pebble smartwatch](https://repebble.com/watch), with wrist-based check-ins.
- [**Tana**](https://github.com/divin/tana) — self-hosted watch-history tracker for [Jellyfin](https://jellyfin.org/).
- [**Memento Mori API**](https://github.com/divin/memento-mori-api) — FastAPI service that computes life statistics (weeks left, percentage lived).
